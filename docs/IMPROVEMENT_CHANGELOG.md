# Improvement changelog

## 1. Trustworthy domain before presentation

The initial shell became a strict normalized model with independent effective, dataset, observed, and checked clocks. Freshness now fails closed when provider-owned time is missing, instead of treating a successful request as proof that a price is current.

## 2. Hand-checkable intelligence

Movement, relative bands, anomaly checks, alerts, and prose briefs became pure deterministic functions. Weak cohorts produce insufficient data; regional prose is emitted only with comparable underlying observations and a sample count.

## 3. Honest jurisdiction adapters

WA gained a real public RSS implementation. NSW/Tasmania gained a credential-aware FuelCheck contract. Restricted or unverified providers gained explicit typed failures and UI explanations. No failed live call falls back to national fixtures.

## 4. Operational behaviour

The app gained an atomic bounded cache, cache-aware error state, source health, user-invoked notification permission, location service, and best-effort background refresh. A generated-Info.plist issue that caused `BGTaskScheduler` registration rejection was found in simulator logs and corrected with an explicit `BGTaskSchedulerPermittedIdentifiers` array.

## 5. Cursor-owned native interface

Cursor CLI using the exact non-fast `cursor-grok-4.6-high` model implemented the visual layer against the tested contracts: full-bleed MapKit, reusable price annotations, true clustering, Grid/Briefs/Monitor/Settings, station evidence, responsive light/dark styling, accessibility identifiers, Dynamic Type-friendly typography, and permission-safe alert setup.

## 6. iOS 26/27 direction without abandoning older devices

The minimum remains iOS 17. iOS 26+ gets availability-gated Liquid Glass; earlier supported systems get a material treatment. The same source builds under the iOS 27 SDK, runs on iOS 26.5 and 27 simulators, and avoids making a beta-only API a product requirement.

## 7. Evaluation and identity

The suite expanded to 27 deterministic unit/integration tests and seven end-to-end UI journeys. A polished no-text app icon and five iOS 27 evidence frames replaced provisional assets and subjective completion claims.
