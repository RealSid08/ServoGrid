# Likely product trajectories

These are bounded next requests, not claims about current functionality.

## 1. Configure an approved jurisdiction

Add provider-issued credentials through a local secure setup flow, validate terms and attribution, prove live payload parsing with sanitized fixtures, then change only that jurisdiction from unavailable to its verified coverage state.

## 2. Route-aware fuel decisions

Let a user choose a destination and compare trustworthy stations along the route. Keep navigation calculation separate from source freshness, and show added travel time alongside any price saving.

## 3. Personal station watchlist

Persist favourite stations and alert preferences locally. Sync should remain optional and must not introduce an account merely to save a favourite.

## 4. Historical cycle view

Show history only from providers whose terms and API support it. Label source gaps, avoid interpolating missing prices as observations, and retain the station/grade/day comparability rule.

## 5. Accessibility and field study

Run the trusted-decision-time protocol with VoiceOver, larger Dynamic Type, reduced motion, light/dark appearance, and physical devices. Use measured confusion and timing—not aesthetic preference alone—to prioritize the next UI revision.
