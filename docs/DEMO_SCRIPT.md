# ServoGrid demo script — under five minutes

## 0:00 — Product promise

Launch ServoGrid. Point out that the map is the first screen and that “Demo data” is always visible. Explain: the app will not make synthetic or stale evidence look live.

## 0:35 — Scan the Grid

Show price annotations across Australia and the grouped cluster over the east coast. Switch from U91 to E10, then back to U91. Use the today/tomorrow control and explain that tomorrow only appears when the selected source supports scheduled prices.

## 1:15 — Inspect one station

Tap a price marker or use the station index. On the sheet, show price, movement/insufficient-data state, relative band, address, source attribution and link, and the separate effective, dataset, observed, and checked timestamps.

## 2:05 — Evidence-backed Briefs

Open Briefs. The fixture produces a reproducible VIC U91 statement based on three comparable stations. Emphasize the displayed sample size and attribution; the engine returns nothing when the evidence threshold is not met.

## 2:45 — Grid Monitor

Open Monitor. Show source state, last success/check, record count, issue count, and the explicit evaluation-fixture message. Explain that production checks include missing/future times, stale snapshots, impossible values, duplicates, empty feeds, schema drift, and source-wide dropout.

## 3:25 — Source honesty

Open Settings. Scroll through the Australian source matrix. Select WA FuelWatch to demonstrate the public live adapter when network access is available; if the network is unavailable, show the honest cached/error state instead. Return to demo for a deterministic close.

## 4:15 — Alerts and privacy

Open alert setup. No system permission appears merely for viewing the form; notification permission is requested only when an alert is enabled. Close with: no account, analytics, tracking, or silent fixture fallback; background checks remain best effort because iOS controls execution.
